# 1. 프로젝트 개요

## 1.1 목적

BootRun은 ICT 분야의 동영상 강의를 들을 수 있는 플랫폼을 구현하는 것을 목표로 합니다.

## 1.2 범위

- 강의 결제 기능
- 동영상 학습 시스템
- 학습 진행 관리(관리자 화면)
- 수료증 발급 시스템

## 1.3 대상 사용자

- 주 타겟: ICT를 처음 배우는 학생

# 2. 기능 요구사항

### 2.1 사용자 관리 (필수)

- 회원가입, 사용자 로그인, 사용자 로그아웃, 관리자 로그인, 관리자 로그아웃 기능 구현
- 사용자 회원가입
    - (필수) 이메일로 회원가입
    - (선택) Google, Github 등 소셜로그인 기능
- 사용자 역할 구분
    - 수강생
    - 관리자: 강의 추가, 학습 진행 상황 모니터링 및 시스템 관리
- 사용자 프로필 관리
    - 프로필 수정(이름, 성별, 생년월일)
    - 수료증 발급
    - 결제 강의 확인
    - 총 학습 시간 표시
    - 수강 가능 기간 표시 (결제 후 2년)
    - 탈퇴

### 2.2 과목 관리 (필수)

- 강의는 프론트엔드, 백엔드, 데이터분석, AI, 디자인, 기타 강의로 분류됩니다.

### 2.3 학습 진행 관리 (필수)

- 관리자 대시보드
    - 강의 생성 및 강좌 추가
    - 일별 접속자 수 표시(동일 IP 1회 처리)
    - 일별 조회수 표시(동일 IP에서 다수 접속했을 경우 다수로 처리)
    - 일별 결제 금액 및 상세 내역 표시
    - 과목별, 전체 진행률 시각화
    - (선택)사용자별 학습 기록
        - 사용자별 일간 접속 현황
        - 사용자별 일간 영상 시청 현황
        - 사용자별 진도 현황
        - 출석부 형태로 PDF 출력 기능
- 학습자 대시보드
    - 회원 정보에 있는 데이터를 학습자가 내 강의 목록에서 항목에서 볼 수 있게 합니다.
    - 개인 학습 진행 상황 표시
    - 남은 미션 및 완료된 미션 표시
- (선택) 학습 기간 만료 전 알림 기능

### 2.4 동영상 학습 시스템 (필수)

- 일반 VOD 강의로 제공되며, 유튜브 링크 임베드 형태로 제공하는 것도 가능합니다.
- 비디오 스트리밍 기능 구현
    - 기본 컨트롤 (재생, 일시정지, 되감기 등)
    - 시청 시간 자동 기록 및 진행률 표시
    - 마지막 시청 지점 저장 및 이어보기 기능

### 2.5 미션 및 평가 시스템

- 과목별 중간, 기말 미션 제공
    - 5지선다형 문제
        - 다음중 javascript의 자료형이 아닌 것은?
    - 코드 제출형 문제
        - 주어진 리스트 내에 홀수를 찾아 합을 반환하는 solution 함수를 완성해주세요.(https://100.jsalgo.co.kr/ 의 1번 문제입니다. js코드를 서버로 받아 실행해도 되고, FE에서 실행하게 해도 됩니다.)
- 자동 채점 기능 구현
- 미션 제출 및 결과 확인 인터페이스

### 2.6 수료 인증 시스템

- 디지털 수료증 발급 및 다운로드 기능
    - 자동으로 이름 및 수료 과목 포함
        - 과목별 수료증
        - 학습 기간 만료 전 알림 기능
        - 대주제 별 수료증
    - PDF 형식으로 추출
- 수료증 진위 확인 시스템 구현

### 2.7 결제 시스템

- 다양한 결제 방식 지원 (신용카드, 계좌이체, 간편결제)
- 결제 내역 조회 기능
- 통합 결제 금액: 50,000원
- 영상 시청 및 수료 가능 기간은 2년
    - 2년 내 수료를 못하더라도 개별 과목 수료증은 남아 있습니다.
    - 추후 결제를 다시 하여 수료를 지속할 수 있습니다.
    - 학습 기간 만료 후 수강을 제한해야 합니다.

- 환불 규정 적용
    - 구매일 1주 이내 및 진도율 10% 미만 시 환불 가능
    - 그 외의 경우 환불 불가
- 영수증 발급 기능
- 쿠폰 발급 및 할인 기능
