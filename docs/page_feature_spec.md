## 1. 필수 과제

1.1 로그인

- 이메일 주소와 비밀번호를 입력받습니다.
- (필수) 이메일 로그인 기능 구현
- (선택) Google, Github 등 소셜 로그인
- 이메일과 비밀번호를 모두 입력하면 `로그인` 버튼이 활성화됩니다. 입력되지 않은 입력창이 있다면 버튼은 비활성화됩니다.
- 로그인 버튼을 클릭하면 이메일 주소와 로그인에 대한 유효성 검사를 진행하며, 이메일 주소 또는 비밀번호가 일치하지 않을 경우에는 경고 문구가 나타납니다.
- 입력창에 focus 시 하단 테두리 색상이 변경됩니다. (회색, #d9dbe0 → 파란색, #2e6ff2)
- 회원가입 페이지로 이동할 수 있는 링크가 있습니다.
- 관리자 계정으로 로그인 시 관리자 페이지로 이동합니다.


1.2 회원가입

- 이메일 주소가 유효한 경우 인증하기 버튼이 활성화됩니다. 가입된 이메일의 경우 경고 문구가 나타납니다.
- 회원가입이 가능한 이메일이면 이메일 입력창 하단에 인증번호 입력창이 출력되고 인증이 완료된 경우 사라집니다.
- 비밀번호는 8~16자의 영문 대/소문자, 숫자, 특수문자를 사용해야 합니다. 유효하지 않을 경우 경고 메시지가 출력됩니다. 유효하지 않은 경우 하단 테두리가 빨간색으로 변경됩니다.
- 비밀번호 확인은 비밀번호와 일치하지 않은 경우 오류 메시지가 출력됩니다.
- 모든 입력이 완료되고 유효성 검사를 통과하면 `가입하기` 버튼이 활성화됩니다.


1.3 메인 페이지

- 서비스 접속 초기화면입니다.
- 강의 목록이 생성된 순서를 기준으로 화면에 출력됩니다.
- 로그인 후에는 사용자 정보가 프로필 카드 형태로 출력됩니다.

1.4 검색

- 상단 헤더의 검색 아이콘을 클릭하면 표시되는 페이지입니다.
- 키워드가 입력된 경우 강의를 검색합니다. 강의명, 강의 설명으로 검색할 수 있습니다.
- 검색 결과는 강의 카드 형태로 표시됩니다.
- 결과가 없을 경우 "검색 결과가 없어요" 메시지가 표시되며, 강의 목록 페이지로 이동하는 버튼을 제공합니다.

1.5 강의 목록

- 전체 과목을 카드 형태로 표시하는 페이지입니다.
- 주제, 유형, 난이도, 가격의 필터링을 설정할 수 있으며, 각 항목에서 속성을 다중으로 선택할 수 있습니다.
 
    
- 프론트엔드, 백엔드, 데이터분석, AI, 디자인, 기타 카테고리별로 탭 형태로 필터링할 수 있습니다.
- 옵션을 다시 클릭하여 필터를 해제하거나, 설정된 필터 우측의 x 버튼으로 해제할 수 있습니다.
- 과목 카드를 클릭하면 강의 상세 페이지로 이동합니다.

1.6 강의 상세
• 선택한 과목의 상세 정보를 표시합니다.
• 상단에 강의 요약정보가 출력되며, 강의 상세 네비게이션이 sticky로 위치하여 페이지 내 이동이 가능합니다.
• 강의 상세, 커리큘럼, 강사소개, FAQ가 포함되며, 수강신청을 누르면 결제 페이지로 이동합니다.
강의 목록은 챕터별로 구조화되어 표시됩니다.
각 강의의 제목, 재생 시간이 표시됩니다.
• (수강 중인 강의인 경우) 시청 완료 여부도 함께 출력됩니다.
강의 상세 정보가 요약되어 있는 카드는 스크롤과 함께 이동합니다.
• (수강 중인 강의인 경우) 학습 진도율과 함께 학습 페이지 이동 버튼을 제공합니다.


1.7 강의 결제 페이지
• 강의 결제를 진행할 수 있는 페이지입니다. 결제할 강의 정보가 표시됩니다.
• 결제 방식을 선택하고 결제를 완료하는 페이지입니다.
• 신용카드, 계좌이체, 간편결제 중 선택할 수 있습니다.
• 결제 약관 동의 체크박스가 있습니다.
• 최종 결제 금액이 표시됩니다.
• 모든 필수 항목을 입력하고 약관에 동의하면 결제하기버튼이 활성화됩니다.
• 결제하기 버튼을 클릭하면 결제 결과 페이지로 이동합니다.
• 이미 결제가 된 강의에 대해서 결제 페이지에 접속하면 안내 메시지가 출력되고 강의 상세로 돌아갑니다.

1.8 결제 결과 페이지
• 결제 완료 정보를 출력하며, 결제가 성공한 경우 강의실로 이동하는 버튼을 제공합니다.
• 결제 실패 시 에러 메시지가 표시됩니다.

1.9 내 강의 목록
• 결제 후 내가 수강할 수 있는 강의를 표시하는 페이지입니다.
• 주제, 유형, 난이도, 가격의 필터링을 설정할 수 있으며, 각 항목에서 속성을 다중으로 선택할 수 있습니다.
• 프론트엔드, 백엔드, 데이터분석, AI, 디자인, 기타 카테고리별로 탭 형태로 필터링할 수 있습니다.
• 옵션을 다시 클릭하여 필터를 해제하거나, 설정된 필터 우측의 x 버튼으로 해제할 수 있습니다.
• 각 과목의 진행률을 표시합니다.
• 과목을 클릭하면 코스 상세 페이지로 이동합니다.


1.10 강의실
• 동영상 플레이어가 전면에 표시되는 페이지입니다.
• VOD 강의 또는 유튜브 임베드 형태로 제공됩니다.
• 기본 컨트롤 (재생, 일시정지, 되감기, 빨리감기, 볼륨 조절, 전체화면 등) 제공
• 시청 시간이 자동으로 기록되며 진행률이 표시됩니다.
• 마지막 시청 지점이 저장되어 이어보기 기능이 제공됩니다.
• 좌측 사이드바에 강의 목록이 표시됩니다.
• 강의 제목이 상단에 표시됩니다.
• 하단에 이전/다음 강의로 이동할 수 있는 버튼이 있습니다.
• 학습 기간이 만료된 경우 시청이 제한됩니다.


1.11 마이페이지 - 프로필 설정
• 사용자의 프로필 정보를 수정할 수 있는 페이지입니다.
• 프로필 사진, 이름, 성별, 생년월일을 수정할 수 있습니다.
• 이메일 주소는 표시만 되고 수정은 불가능합니다.
• 입력창에서 포커스를 잃으면 유효성 검사가 진행됩니다.
• 유효성 검사를 통과하면 수정하기버튼이 활성화됩니다.


1.12 관리자 페이지 - 대시보드
• 관리자 전용 페이지로, 전체 시스템 현황을 확인할 수 있습니다.
• 일별 접속자 수가 차트로 표시됩니다 (동일 IP 1회 처리).
• 일별 조회수가 차트로 표시됩니다 (동일 IP 다수 접속 시 다수 처리).
• 일별 결제 금액이 차트로 표시됩니다.
• 상세 내역을 테이블 형태로 확인할 수 있습니다.
• 과목별 진행률이 파이차트 또는 바차트로 시각화되어 표시됩니다.


1.13 관리자 페이지 - 사용자 관리
• 등록된 사용자 목록을 확인하고 관리할 수 있는 페이지입니다.
• 사용자 이름, 이메일, 가입일, 마지막 접속일, 수강 상태가 테이블로 표시됩니다.
• 검색 기능을 통해 특정 사용자를 찾을 수 있습니다.
• 각 사용자를 클릭하면 상세 정보를 확인할 수 있습니다.
• (선택) 사용자별 학습 기록을 조회할 수 있습니다


1.14 관리자 페이지 - 강의 관리
• 강의와 챕터를관리할 수 있는 페이지입니다. 강의 목록이 테이블로 표시됩니다.
• 새 강의 추가 버튼이 있습니다. 강의를 추가하고 수정할 수 있습니다.
• 기본 강의 정보, 커리큘럼 추가, 미션을 추가할 수 있습니다.


1.15 관리자 페이지 - 결제 관리
• 결제 내역을 관리할 수 있는 페이지입니다.
• 전체 결제 내역이 테이블로 표시됩니다.
• 결제일, 사용자 이름, 결제 금액, 결제 방식이 표시됩니다.
• 환불 승인/거절 버튼이 있습니다.
• 날짜별 필터링 및 검색 기능이 제공됩니다.
• 엑셀 다운로드 기능이 있습니다.



1.16 404 메인 페이지
• 존재하지 않는 페이지에 접근했을 때 표시되는 오류 페이지입니다.
• "페이지를 찾을 수 없습니다" 메시지가 표시되며, 404 일러스트레이션이 표시됩니다.
• 메인 페이지로 돌아가기 버튼이 있습니다.



## 2. 선택(도전) 과제
2.1 미션 페이지
• 중간 미션과 기말 미션이 구분되어 표시됩니다.
• 미션의 제목, 문제 수, 제출 여부가 표시됩니다.
• 두 가지 유형의 문제가 제공됩니다:
• 5지선다형 문제: 문제가 상단에 표시되고, 5개의 보기 중 하나를 선택
• 코드 제출형 문제: 문제 설명과 함께 코드 에디터가 제공되며, 코드를 작성하여 제출
코드 실행 버튼을 눌러 결과를 미리 확인할 수 있습니다.
제출 버튼을 클릭하면 자동 채점이 진행됩니다.



2.2 마이페이지 - 수료증 관리
• 발급받은 수료증을 확인하고 다운로드할 수 있는 페이지입니다.
• 과목별 수료증 목록이 카드 형태로 표시됩니다.
• 각 수료증에는 과목명, 수료일이 표시됩니다.
• PDF 다운로드 버튼이 있습니다.
수료증은 자동으로 이름 및 수료 과목이 포함됩니다.
수료 조건을 만족하지 못한 과목은 수료증이 표시되지 않습니다.


2.3 마이페이지 - 결제 내역
• 결제 내역을 조회할 수 있는 페이지입니다.
• 결제일, 결제 금액, 결제 방식이 표시됩니다.
• 영수증 보기 버튼이 있습니다.
• 환불 가능 여부가 표시됩니다 (구매일 1주 이내 및 진도율 10% 미만).
• 환불 가능한 경우 환불 신청 버튼이 표시되며, 클릭 시 확인 모달이 나타납니다.
• 수강 가능 기간 (결제 후 2년)이 표시됩니다.


2.4 수료증 진위 확인 페이지
• 수료증의 진위를 확인할 수 있는 공개 페이지입니다.
• 수료증 번호를 입력받는 입력창이 있습니다.
• 조회 버튼을 클릭하면 수료증 정보가 표시됩니다.
• 유효한 수료증인 경우: 수료자 이름, 과목명, 수료일이 표시됩니다.
• 유효하지 않은 수료증인 경우: "유효하지 않은 수료증입니다" 메시지가 표시됩니다.


2.5 학습 기간 만료 알림
• 학습 기간 만료 7일 전부터 알림이 표시됩니다.
• 로그인 시 팝업 또는 상단 배너로 알림이 표시됩니다.
• 마이페이지에서 남은 학습 기간이 강조되어 표시됩니다.
• 알림을 클릭하면 강의 수강 페이지로 이동합니다.


2.6 관리자 페이지 - 사용자별 학습 기록
• 사용자별 상세 학습 기록을 조회할 수 있는 페이지입니다.
• 사용자를 검색하거나 목록에서 선택할 수 있습니다.
• 사용자별 일간 접속 현황이 달력 형태로 표시됩니다.
• 사용자별 일간 영상 시청 현황이 차트로 표시됩니다.
• 사용자별 진도 현황이 과목별로 상세히 표시됩니다.
